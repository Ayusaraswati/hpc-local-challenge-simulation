# 🚀 Bridging Global Infrastructure to Address Local Challenge with HPC

Repositori ini berisi studi kasus dan contoh implementasi kode pemrosesan paralel untuk memodelkan solusi atas tantangan lokal (seperti simulasi evakuasi bencana dan analisis wilayah) berdasarkan materi kuliah praktisi **"Bridging Global Infrastructure to Address Local Challenge with HPC"** oleh Asst. Prof. Dr. Worawan Diaz Carbalo.

## 🧠 Latar Belakang & Studi Kasus
Tantangan lokal seperti mitigasi bencana dan pengaturan evakuasi membutuhkan simulasi berbasis agen dalam jumlah besar. Komputasi standar sering kali lambat, namun dengan pendekatan **High-Performance Computing (HPC)** melalui paralelisasi tugas, kalkulasi kompleks dapat dipecah secara simultan untuk mempercepat pengambilan keputusan.

## 📂 Struktur Repositori
- `src/hpc_simulator.py`: Skrip utama pemrosesan paralel untuk simulasi zona evakuasi.
- `requirements.txt`: Daftar dependensi library Python.
